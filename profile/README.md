## 408实验室

仓库简介
* 仓库用于Robocon队伍的项目代码管理
* 仓库不仅用于赛季项目，也将作为技术积累

仓库开发建议
* 代码提交用.ignore避免提交编译好的文件，会不必要的增加仓库大小和提交时间
* 电控组和视觉组依赖于main分支开发每一年的分支
* 每一年结束时，总结分支合并到main之中，来保持main的更新
* 组长或者组员提交者注意标注清楚每一次提交的message，参考已有仓库
* 组长应当尽量维护主仓库而不是另开新仓库，会导致仓库膨胀不易管理
* 组长务必用md来就每个仓库或分支进行概述，避免后人看不懂
* 代码方面尽量有像人写的注释，保持简洁和规范

仓库历史
* 仓库从2024年依附于25年RC开始创制，仓库原始创始为Hrilug，如果后续关于仓库的管理问题直接联系
